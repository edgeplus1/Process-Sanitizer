# Process Sanitizer

<img width="512" height="512" alt="icon" src="https://github.com/user-attachments/assets/63368732-0aea-4f04-8da8-d2f36dc7ff3e" />

**Process Sanitizer** — это портативный эвристический детектор подозрительных процессов, майнеров и вредоносного программного обеспечения для операционных систем семейства Windows. Приложение анализирует поведение процессов, проверяет цифровые подписи, сверяет хеши с локальной базой и сканирует механизмы автозагрузки, не требуя установки и не оставляя следов в реестре системы.

## Quick Start (Быстрый старт)

1. Скачайте актуальную версию со страницы [Релизы](https://github.com/edgeplus1/Process-Sanitizer/releases).
2. Распакуйте архив в любую папку.
3. Запустите `Process_Sanitizer.exe` **от имени администратора**.
4. Нажмите **«Скан»** или включите **«Автообновление»** в настройках.
5. При обнаружении угрозы используйте контекстное меню (правый клик) для завершения, помещения в карантин или добавления в белый список.

## Основные возможности

### Многоуровневый эвристический анализ
- Выявление маскировки под системные процессы (`svchost`, `explorer` и др.)
- Обнаружение запуска из подозрительных директорий (Temp, AppData, Downloads)
- Проверка отсутствия цифровой подписи файла

### Проверка подлинности
- Использование WinVerifyTrust для валидации цифровых подписей
- Определение имени подписанта (CN из сертификата)
- Поддержка каталожных подписей Windows

### Локальная база угроз и эталонов
- Поддержка списков BAD/GOOD хешей (SHA256)
- Возможность снятия baseline-эталонов с заведомо чистой системы
- Локальное хранение в текстовых файлах рядом с exe

### Поведенческий анализ с памятью
- Отслеживание мгновенной нагрузки при запуске (< 60 секунд)
- Детекция устойчивой аномальной активности (CPU >= 85% в течение 2+ сканов)
- Память поведения: процесс остается помеченным даже при снижении нагрузки
- Уровни риска: SAFE, LOW, MEDIUM, HIGH, CRITICAL, DEAD

### Мониторинг ресурсов
- Живой график нагрузки системы (CPU, RAM, GPU, Disk IO)
- Нативная отрисовка через GDI+ без сторонних библиотек
- Кольцевой буфер на 120 замеров (~6 минут при интервале 3 сек)

### Безопасные действия
- **Завершение процессов** с защитой критических компонентов Windows
- **Карантин** файлов с сохранением метаданных (SHA256, исходный путь, время) и возможностью восстановления
- **Сторож возврата**: автоматическое обнаружение попыток восстановления помещенных в карантин файлов
- **Принудительное уничтожение (Force)**: завершение дерева процессов, безвозвратное удаление файла и очистка связанных записей автозагрузки (с поддержкой отложенного удаления при перезагрузке через MoveFileEx)

### Сканер автозагрузок
- Проверка ключей реестра (Run/RunOnce для HKCU и HKLM)
- Сканирование папок автозагрузки
- Анализ служб Windows через WMI
- Проверка задач планировщика через COM (Schedule.Service)
- Кросс-проверка: работающий интерпретатор с параметрами из автозагрузки = мгновенный CRITICAL

### Экспорт отчетности
- Сохранение детального отчета о состоянии системы в форматах TXT и HTML
- HTML-отчет с цветными таблицами и стилями
- Включение данных о процессах, карантине и автозагрузках

### Фоновая работа
- Сворачивание в системный трей
- Всплывающие уведомления (balloon) об обнаруженных угрозах
- Настройка интервала автообновления (3/5/10 секунд)

### Автообновление
- Встроенный механизм проверки актуальных релизов через GitHub API
- Скачивание новой версии напрямую в папку "Загрузки"
- Проверка через HTTPS с официального репозитория

## How it works (Как это работает)

1. **Сбор:** Приложение опрашивает систему через WinAPI и WMI, собирая список активных процессов и точек автозагрузки.
2. **Анализ:** Каждый процесс проходит через эвристический фильтр (путь, имя, подпись) и поведенческий анализатор (память нагрузки CPU/GPU).
3. **Сверка:** Хеши исполняемых файлов проверяются по локальным базам BAD (черный список) и GOOD (белый список).
4. **Действие:** На основе накопленного уровня риска (SAFE — CRITICAL) пользователь получает уведомление и может изолировать или уничтожить угрозу.

## Технические требования

- **Операционная система:** Windows 7 / 8.1 / 10 / 11
- **Фреймворк:** .NET Framework 4.7.2
- **Архитектура:** Any CPU / x64
- **Зависимости:** Отсутствуют. Приложение является полностью портативным (Portable).
- **Права доступа:** Для полного функционала (чтение владельцев процессов, завершение чужих процессов, сканирование системных служб) требуется запуск от имени администратора.

## Сборка из исходного кода

1. Клонируйте репозиторий:

```bash
git clone https://github.com/edgeplus1/Process-Sanitizer.git
```

Откройте файл решения Process_Sanitizer.sln в Visual Studio 2019 или новее.

В верхней панели переключите конфигурацию сборки на Release.

Выберите Сборка -> Пересобрать решение (или нажмите Ctrl+Shift+B).

Готовый исполняемый файл будет находиться в директории:

Копировать
bin\Release\Process_Sanitizer.exe
Структура проекта

